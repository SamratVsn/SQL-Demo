# SQL Demo

A native Android project exploring local database operations, built with Kotlin.

## About

This is a practice/demo project focused on working with SQL-based data persistence in Android — covering the basics of storing, querying, and managing structured data locally within an app. It's a learning project rather than a standalone consumer app.

## Built With

- **Kotlin**
- **Android SDK**
- **Gradle** (Kotlin DSL)

## Project Structure

Standard Android Studio / Gradle project layout:

SQL-Demo/
├── app/                  # Main application module
├── gradle/               # Gradle wrapper files
├── build.gradle.kts      # Project-level build config
└── settings.gradle.kts   # Module settings

## Running the Project

1. Clone the repo:
   git clone https://github.com/SamratVsn/SQL-Demo.git
2. Open the project in **Android Studio**.
3. Let Gradle sync, then run on an emulator or physical device.
